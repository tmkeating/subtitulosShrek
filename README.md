# Subtítulos para Shrek
Subtítulos para el doblaje castellano de Shrek en España. Deberían ser 100% precisos con todos los voces y sus momentos.

Hay dos versiones: Una con letras de música de fondo y la otra sin. 

Es posible que necesites sincronizar el momento de los subtítulos con tu especifico archivo de la película.

¡Espero que disfrutes!
